# 3주차 과제 - 그래픽스 파이프라인과 셰이더

-과제 1
6단계에서는 모델 행렬과 카메라 행렬을 이용하여 바닥과 공을 3차원 공간에 배치하고, 공이 시간에 따라 회전하도록 구현하였다.

바닥은 Y축 방향으로 -0.06만큼 이동시켜 윗면이 y = 0에 위치하도록 설정하였다. 공은 Y축 방향으로 1.9만큼 이동시켜 바닥 위에 떠 있도록 하였다.
공에는 M4.rotateY(time * 0.8)을 적용하여 시간이 지남에 따라 Y축을 중심으로 회전하도록 하였다.

실습 결과 및 분석
모델 행렬을 이용하여 바닥과 공을 각각 원하는 위치에 배치할 수 있도록 구현하였다. 공은 바닥 위의 일정한 위치에서 Y축을 중심으로 자전한다.
8단계에서는 프래그먼트 셰이더를 수정하여 기존의 조명 계산 대신 법선 벡터의 방향을 색상으로 표현하였다.
이번 실습에서는 법선 벡터의 각 성분을 RGB 색상에 대응시켜 표면의 방향에 따라 서로 다른 색이 나타나도록 변경하였다.
주요 코드
void main() {
  vec3 N = normalize(vNormal);
  fragColor = vec4(N * 0.5 + 0.5, 1.0);
}

실습 결과 및 분석
구는 표면의 위치에 따라 법선 벡터의 방향이 연속적으로 달라지므로 다양한 색상이 나타난다.

-과제 2
제작 의도
이번 실습에서는 자연적으로 형성된 행성이 아닌, 고도로 발달한 기계 문명에 의해 만들어진 사이버네틱 행성을 표현하고자 하였다. 일반적인 행성은 암석, 대기, 구름, 용암 등 자연적인 요소로 구성되지만, 내가 구상한 행성은 표면 전체가 금속 패널과 전자회로로 이루어진 거대한 인공 구조물이다.
이러한 주제를 선택한 이유는 사이버펑크 특유의 어둡고 차가운 분위기와 미래적인 기술의 느낌을 동시에 표현하고 싶었기 때문이다. 행성의 기본 색상은 어두운 남색과 검은색에 가깝게 설정하고, 표면에 청록색과 분홍색의 네온 회로가 나타나도록 하였다. 이를 통해 보는 사람이 단순한 천체가 아니라 내부에서 수많은 전자 장치와 에너지가 작동하는 거대한 기계 행성을 바라보는 듯한 느낌을 받도록 하고자 하였다.

구현 방법

주요 코드
vec2 uv = vec2(
    atan(S.z, S.x) / 6.2831853 + 0.5,
    asin(clamp(S.y, -1.0, 1.0)) / 3.14159265 + 0.5
);

vec2 panel = uv * vec2(42.0, 22.0);
vec2 cell = fract(panel);
vec2 id = floor(panel);

fract()는 좌표의 소수 부분만 추출하므로 각 패널 내부에서 반복되는 위치를 계산할 수 있고, floor()는 현재 위치가 어느 패널에 속하는지를 구분한다. 이를 이용하여 구의 곡면 위에도 규칙적인 금속 패널 구조를 표현할 수 있었다.

네온 회로 패턴

사이버네틱한 분위기를 가장 직접적으로 보여주는 요소는 행성 표면에 나타나는 네온 회로이다. 회로는 수평선, 수직선, 분기선, 연결 지점으로 구성하였다.

주요 코드
float row = 1.0 - smoothstep(
    aa, aa * 2.5, abs(cell.y - 0.5)
);

float column = 1.0 - smoothstep(
    aa, aa * 2.5, abs(cell.x - 0.74)
);

float nodeA = 1.0 - smoothstep(
    0.035, 0.065,
    distance(cell, vec2(0.74, 0.5))
);

float traces = clamp(
    horizontal + vertical + branch + nodeA + nodeB,
    0.0, 1.0
);

abs(cell.y - 0.5)는 패널의 중앙 수평선에서 얼마나 떨어져 있는지를 계산하고, smoothstep()은 그 거리에 따라 선의 밝기가 부드럽게 변하도록 한다.

금속 표면의 질감

회로가 없는 부분은 매끄러운 단색으로 처리하기보다 어두운 금속 재질처럼 보이도록 잡음 함수를 활용하였다.

주요 코드

float surfaceNoise = fbm(
    S * 8.0 + vec3(0.0, uTime * 0.012, 0.0)
);

float plateNoise = noise3(S * 18.0);

vec3 metal = mix(
    vec3(0.012, 0.025, 0.055),
    vec3(0.035, 0.075, 0.12),
    smoothstep(0.25, 0.8, surfaceNoise)
);

metal *= 0.82 + 0.18 * plateNoise;
metal *= 1.0 - seams * 0.55;

noise3()는 좌표에 따라 불규칙하지만 부드럽게 변화하는 값을 생성하고, fbm()은 서로 다른 크기의 잡음을 여러 번 합쳐 복잡한 표면 질감을 만든다.

이를 통해 표면이 단순한 검은색 구체가 아니라 미세한 색상 변화와 패널 경계를 가진 인공 구조물처럼 표현되도록 하였다.

시간에 따라 점멸하는 네온 신호

행성이 살아 있는 기계처럼 느껴지도록 회로의 밝기가 시간에 따라 변화하는 효과를 추가하였다.

주요 코드

float signal = 0.5 + 0.5 * sin(
    uTime * 2.4 + dot(id, vec2(0.71, 1.13))
);

vec3 neon = mix(
    vec3(0.02, 0.95, 1.0),
    vec3(1.0, 0.08, 0.72),
    step(0.82, hash31(vec3(id, 2.0)))
);

color += neon * traces * (0.55 + 0.65 * signal);

sin() 함수는 시간에 따라 주기적으로 변화하는 값을 생성한다. 여기에 uTime을 사용하여 회로의 밝기가 지속적으로 변하도록 하였다.
네온 색상은 청록색과 분홍색을 사용하였으며, hash31()과 step()을 통해 패널별로 색상이 선택되도록 하였다. 이러한 효과는 행성 전체에서 디지털 신호가 작동하고 있다는 느낌을 강조한다.

조명과 가장자리 발광 효과

주요 코드

vec3 N = normalize(vNormal);
vec3 L = normalize(vec3(0.8, 0.32, 0.5));

float diff = max(dot(N, L), 0.0);

float rim = pow(
    1.0 - max(dot(N, L), 0.0),
    3.0
);

vec3 color = metal * (0.16 + 0.84 * diff);

color += neon * traces * (0.55 + 0.65 * signal);
color += vec3(0.02, 0.28, 0.48) * rim * 0.75;

dot(N, L)은 표면이 빛을 향하는 정도를 계산한다. 빛을 정면으로 받는 부분은 밝게, 반대쪽은 어둡게 표현하여 구의 입체감을 나타냈다.

추가로 rim 값을 계산하여 빛을 직접 받지 않는 방향의 표면에 청록색 계열의 발광 효과를 더하였다. 이를 통해 어두운 금속 표면과 밝은 네온 회로 사이의 대비를 강조하였다.
